# Adobe Stock Remotion — Antigravity Workflow Guide

A step-by-step guide page: open the Adobe-Stock-X-Remotion repository in Antigravity IDE and paste the 7 prompts one by one, in order — from automatic installation and a verified sample video, through 100 unique motion-background prompts, validation, a 3-video test, batch rendering, to the final Adobe Stock QA report with titles and keywords.

Each prompt is presented exactly as written, with a plain-language explanation of when to give it, what it will do, and what to check afterwards — plus a workflow timeline, category chart, technical spec diagrams, the full production guide from the "Adobe X Remotion Guide Document", a common-errors FAQ, and WhatsApp community channels.
